## 💡 How to Submit a Pull Request

1. Fork the target repository on GitHub.
2. Edit their `README.md` and insert the entry into the alphabetical position.
3. Commit with a conventional commit message:
   ```text
   docs: add Everything Gemini to agent frameworks
   ```
4. Open the Pull Request linking to [https://github.com/salmandev/everything-gemini](https://github.com/salmandev/everything-gemini).
