Hey everyone!

Following Google Research's release of *Harness²: Recursive Agent Harnessing for an Open World* (arXiv:2610.14224), we just shipped **Everything Gemini v2.1.0**.

### What is Harness²?
Instead of expensive model fine-tuning, Harness² formalizes agent optimization around 8 file-based surfaces: Prompts, Guardrails, Memory, Guidance, Subagents, Skills, Scripts, and Plugins. At test time, agents execute a **Propose-Probe-Compose** loop to mutate their own harness and pass deterministic verification gates.

### What Everything Gemini v2.1.0 Adds:
1. **`harness2-recursive-optimization`**: Skill implementing Propose-Probe-Compose cycles and continual harness learning.
2. **`google-flow-orchestrator`**: Cyclic multi-agent graph state machine with human-in-the-loop pauses.
3. **`dataproc-spark-analytics`**: Serverless Spark / PySpark batch processing and Gemini embedding UDFs for probe scoring.
4. **`everything-gemini harness2`**: Instant CLI synthesizer for canonical 8-surface Harness² workspaces with `harness.yaml`.
5. **Python SDK Showcase**: `examples/python-sdk/harness2_recursive_loop.py` demonstrating autonomous harness mutation.

Everything is zero-dependency and open-source (Apache 2.0).
